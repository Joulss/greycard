# §633. French translation of the window

*2026-11-11*

The translation foundation in §616 now has a French catalog for the
window. Its wording uses consistent photographic terms across controls:
Développement, Hautes lumières, Clarté, Correction du voile, and
Étalonnage des couleurs, among others. The catalog's header records
the lexicon so later translations can keep those choices consistent.

English remains the source language for any string not translated in
the catalog. This note covers the words themselves; choosing English
explicitly in the Language picker and making room for longer slider
labels are separate changes.
