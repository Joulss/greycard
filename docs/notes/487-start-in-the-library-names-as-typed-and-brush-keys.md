# §487. Start in the Library, names as typed, and brush keys

*2026-11-01*

Three asks from the testers in one landing.

**Start in: Loupe or Library.** A second segmented row under
Settings' Start in, saved as `start_view` and read leniently, anything
unknown reading as Loupe. At launch the Library opens when `--grid`
asks or the setting says so; a file named on the command line, a
capture or timing run, or a culling flag keeps the Loupe, and a
folder named on the command line follows the setting. The start
folder of folders (§459) opens as its library view as before,
whatever the setting says.

**A mask's name as typed.** The capitals came from the Section's
owner in the controls, which uppercased the mask's name before every
section title it heads. The owner now shows as typed, with its letter
spacing dropped; the section titles and a shape card's kind stay in
capitals. Nothing records whether a name was typed or generated, so
"Subject 3" and "Adjustment 2" show in their own case too.

**Brush and Show mask keys.** With the brush in hand, Shift+[ and
Shift+] take the feather down or up a tenth and Ctrl+[ and Ctrl+]
the flow, held to 0 to 1, repeating through the system's key repeat
so a lost focus stops them; in the grid Shift+[ and Shift+] still
step a frame within its stack (§486), since the grid takes them
first. O turns the chosen mask's Show mask on or off in Develop, as
Lightroom's overlay key does, and is rebindable as `show-mask`; the
bracket pairs are fixed like the other two-key rows. Shift+[ and ]
are Lightroom's feather keys; Alt was out for the flow since Option+[
types a character on a Mac, and - and = read as zoom. Text fields
keep the keys when they have focus. Each has its row on the keys
sheet.
