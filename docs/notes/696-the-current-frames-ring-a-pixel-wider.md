# §696. The current frame's ring, a pixel wider (2026-11-15)

§687 gave every frame in a set a full 2 px ring in the strip, the set's
in the accent at 60%, the current one's in `accent-text`. The set showed,
but the current frame was then told from it by strength alone, and the
owner found it harder to pick out than before.

The current frame's ring is now 3 px. The extra pixel is drawn over the
picture's edge, so nothing moves. The set's ring is as §687 left it.

Tried beside it (captures in `target/captures-2026-11-15/set-mark-current/`,
a sheet a theme):

- The set's ring at 40%, alone or with the wider current ring: the current
  frame stands out, but the set fades back toward where §687 found it.
- A 1 px keyline inside the current ring, in the opposite tone: one edge
  always contrasts with the picture (8:1 or better), but at the strip's
  size it does not read at a glance.

Against the strip's ground the set's ring is 3.72:1, 2.83:1, and 1.55:1
(Charcoal, Grey, Light) and the current's 6.91:1, 4.65:1, and 5.77:1, as
before; the width is what changed. The grid is untouched.
